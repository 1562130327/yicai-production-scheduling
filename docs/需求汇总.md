整理日期: 2026-06-20

---

## 一、总体目标
1. 把生产排单表做成网页版，让人一目了然不眼花
2. 界面采用气泡式布局（订单气泡、师傅气泡、机器气泡、零工气泡）
3. 最终目标是做成微信小程序，方便师傅自己更新进度
4. 每台机器能直观看到用了哪些师傅和多少零工配合

## 五、订单录入信息

- 订单编号（跟单员自己输入）
- 产品型号
- 客户名
- 加工工艺（下拉选择）
- 优先级（普通/注意/特急/低）
- 客户要求交期
- 用料（材料+颜色，对应排单表格式如"白色38°B料EVA（岳东）"）
- 片材尺寸（如1.4m*3m*5mm，给破片师傅看的要破多厚）
- 片材数量
- 原材料尺寸（用于系统算料）
- 产品尺寸（客户需要的最终尺寸，可多个）
  - 支持单层：100*234*10mm
  - 支持多层粘合：100*234*（7+3）mm
  - 支持打断：一张3m片材打断成多张不同尺寸
  - 多层时需标记每层是冲型还是切片
- 是否拿回老厂生产
- 备注（包括打边的长宽特定要求）
- 是否需要贴布/背胶
- 是否外发加工
- 是否直接加工（外来材料）

## 六、权限体系

### 管理员
- 全部权限
- 创建/编辑/删除订单
- 确认完单（完单后移出生产列表，保留本地可查）
- 配置流程（设定需要什么机器、多少零工、哪位师傅）
- 设定零工人数
- 设定优先级
- 管理师傅（增删改负责人）
- 查看日报
- 查看库存
- 处理反馈
- 安排明日待办

### 跟单员
- 创建订单
- 设定优先级（可附注客户要求交期）
- 查看库存
- 查看日报
- 查看师傅反馈的问题
- 反馈问题

### 师傅
- 只能看到自己的订单和流程步骤
- 标记自己步骤完成（完单后通知管理员和跟单员）
- 可同时进行多单或只进行一单
- 调整进行中订单的零工人数
- 反馈未生产的单需要多少零工（给管理员）
- 录入每日进度（已完成多少数量）
- 提交反馈：
  - 数量问题 → 反馈给上一步负责人（第一步反馈给跟单+管理员）
  - 材料问题 → 反馈给跟单员+管理员
  - 人员不足 → 反馈给跟单员+管理员
  - 机器故障 → 反馈给管理员
- 无密码登录（按名字直接进入）

### 零工
- 不需要登录
- 仅作为记录用途

## 七、生产流程与反馈机制

### 流程规则
- 一个单的流程不是等全部完成才算完
- 到某个师傅那个步骤他完成了，就算他完单
- 横竖分切机两种情况：
  - 作为流程第一步 → 反馈给跟单和管理员
  - 作为片材后分切 → 反馈给破片机那一步
- 直接加工的单（前面没步骤）→ 反馈给跟单和管理员
- 库存用完的单 → 最后一步反馈数量已做完，再按正常流程走
- 拿回老厂的单 → 最后一步=完单，跟单员可反馈补料

### 反馈流向
| 问题类型 | 反馈对象 |
|----------|----------|
| 数量问题 | 上一步负责人（第一步→跟单+管理员） |
| 材料问题 | 跟单员+管理员 |
| 人员不足 | 跟单员+管理员 |
| 机器故障 | 管理员 |

## 八、每日工作流

### 师傅每日
- 登录后看到待办订单列表和反馈消息
- 及时完单可马上更新状态
- 进行中但未完成的订单录入完成进度
- 反馈材料/人员/数量问题

### 跟单员每日
- 录入新订单
- 录入明日要安排的单
- 查看日报（订单状态+库存+人员+问题）
- 库存缺口提醒

### 管理员每日
- 录入明日排单
- 确认完单
- 处理反馈
- 设定零工人数

## 九、库存与算料

### 库存表联动
- 原材料有9个供应商：岳东、辉煌、宏泰、盛达、易升、福能、轩宇、腾鑫、东葳
- 库存表按周分Sheet，记录每日入库/出库

### 材料对应关系
- 排单表"白色38°B料EVA（岳东）" = 库存表"白38°B料"（岳东）
- 排单表"黑色38°B料EvA（福能）" = 库存表"黑38°B料"（福能）

### 厚度规则
- 58mm原材料按60mm算
- 54mm原材料按55mm算（最多可开到56-57mm）

### 实际尺寸
| 标称 | 实际 |
|------|------|
| 1m | 1.05m |
| 1.2m | 1.27m |
| 1.4m | 1.46m |
| 1.5m | 1.55m |
| 3m | 3.05-3.09m |

### 算料规则
- 用料厚度18mm → 最优用54mm原材料
- 一床原材料可开片数 = 原材料厚度 ÷ 用料厚度（向下取整）
- 例：60mm ÷ 5mm = 12张, 60mm ÷ 25mm = 2张
- 切片需计算一张原材料能切多少片
- 两种切法：直接按长宽切（快）vs 套料切（省材料）
- 具体用什么宽度的原材料也要根据供应商有什么材料来

## 十、打印功能

- 打印到A4纸上
- 每个师傅只打印属于自己的步骤
- 打印内容包含：客户、用料、数量

### 郑思远特殊（分两份打印）
- 打边任务（明日待开始的新订单）：包含用什么原材料、多少床、什么颜色
- 分切任务（进行中订单，流程到他的）：包含片材数量和分切数量

### 其他师傅
- 打印进行中且流程到他的订单

### 直接加工订单
- 单独打印

## 十一、其他细节

- 师傅最好只能看到自己的订单
- 师傅进系统按编辑好的名字登录，不用密码
- 管理员可增删改负责人
- 跟单员可在优先级后注明客户要求多久要货
- 老厂的单在订单分类里显示
- 每日汇总要求负责人录入订单状态
- 库存信息要根据所有订单估算材料有无缺口
