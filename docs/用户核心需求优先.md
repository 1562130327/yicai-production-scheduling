# 用户核心需求 - 优先实现

## 一、用户的核心想法（必须优先）

### 1.1 订单流程
- 订单从横竖分切机开始（郑思远）
- 每个师傅完成后传给下一位
- 每个师傅都要标记完成进度
- 暂停、转单是实际情况

### 1.2 人员安排
- 固定岗位：郑思远、伍乾进、莫齐国、李乐
- 非固定岗位：周忠琼、简翠花、杨合进
- 零工配合：每个工序需要不同数量的零工

### 1.3 材料计算
- 单订单计算
- 多订单配套计算（同一家供应商同规格原材料）
- 最佳方案：把一床原材料尽量用完，同时完成订单，尽量少产生库存
- 切割优化：提供方案给师傅选择

### 1.4 反馈系统
- 材料数量问题
- 材料质量问题
- 弄坏材料
- 人员不足
- 机器故障
- 正确传导给相关人员

### 1.5 主页设计
- 车间地图风格
- 显示进行中的订单
- 每个订单的流程进度
- 每台机器的人员安排

## 四、核心原则

**用户的想法是最适配车间的，行业实践只是参考。**

- 不要为了追求"标准"而忽略用户的实际需求
- 用户的业务逻辑是核心
- 行业实践是用来补充，不是用来替代
