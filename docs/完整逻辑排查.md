## 三、材料计算排查

### 3.1 当前计算逻辑

```javascript
// 一床可开片数
sheetsPerBed = Math.floor(rawMaterialThickness / productThickness)

// 一张原材料可切片数
piecesPerSheet = Math.floor(actualRawWidth * 1000 / productWidth) * 
                 Math.floor(actualRawLength * 1000 / productLength)

// 需要原材料张数
sheetsNeeded = Math.ceil(productQty / (sheetsPerBed * piecesPerSheet))
```

### 3.2 需要补充的逻辑

| 功能 | 状态 | 说明 |
|------|------|------|
| 基础计算 | ✅ | 一床可开片数、一张可切片数 |
| 厚度换算 | ✅ | 58mm→60mm, 54mm→55mm |
| 尺寸换算 | ✅ | 1m→1.05m, 1.4m→1.46m |
| 打边计算 | ❌ | 没有考虑打边备注 |
| 套料切 | ❌ | 没有套料切算法 |
| 库存扣减 | ❌ | 计算后没有自动扣减库存 |
| 原材料推荐 | ❌ | 没有根据库存推荐原材料 |

## 五、修复优先级

1. **订单编辑功能** - 跟单员需要修改订单
2. **订单取消功能** - 管理员需要取消订单
3. **领料关联库存** - 订单领料时自动扣减库存
4. **交期提醒** - 主页显示快到期订单
5. **材料计算补充** - 打边计算、套料切
6. **操作日志查看** - 管理员查看操作记录
