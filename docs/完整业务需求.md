### 1.2 数据需求

- 每个流程的人事安排
- 每台机器的当前状态

---

## 二、订单状态流转

### 2.1 正常流程
```
待排产 → 进行中（第一步开始）→ 生产中 → 已完成
```

### 2.2 触发条件
- 师傅点击"开始任务" → 状态变为"进行中"
- 所有工序完成 → 状态变为"已完成"

### 2.3 特殊状态
- 暂停：师傅可以暂停任务
- 转单：订单可以转给其他师傅

---

## 三、师傅标记功能

### 3.1 可用操作
| 操作 | 说明 |
|------|------|
| 开始任务 | 标记工序开始 |
| 完成进度 | 输入完成数量 |
| 暂停任务 | 暂停当前工序 |
| 完成任务 | 标记工序完成 |

### 3.2 进度计算
- 总数量：订单中该工序需要完成的总数
- 已完成：师傅输入的完成数量
- 完成率：已完成/总数量

---

## 四、反馈系统

### 4.1 反馈类型
| 类型 | 说明 | 传导对象 |
|------|------|----------|
| 材料数量问题 | 材料多或少 | 上一步+跟单+管理员 |
| 材料质量问题 | 材料本身问题 | 跟单+管理员 |
| 弄坏材料 | 操作失误 | 上一步+跟单+管理员 |
| 人员不足 | 需要更多零工 | 管理员 |
| 机器故障 | 机器问题 | 管理员 |

### 4.2 传导规则
- 第一步反馈 → 跟单+管理员
- 其他步骤反馈 → 上一步+跟单+管理员

---

## 五、材料计算

### 5.1 单订单计算
- 输入：订单的原材料规格、需要的片材厚度和数量
- 输出：需要多少张原材料、最佳切法

### 5.2 多订单配套计算
- 输入：多个同规格原材料的订单
- 输出：最佳配套方案，尽量用完原材料

### 5.3 方案选择
- 提供多种方案供选择
- 选择的方案记录给开片师傅

### 5.4 切割优化
- 直切机：计算一张片材怎么切最省材料
- 横竖分切机：计算分切方案

---

## 六、权限控制

### 6.1 师傅权限
- 看到：自己的任务、订单基本信息、反馈入口
- 看不到：其他师傅的任务、管理功能

### 6.2 跟单员权限
- 看到：自己录入的订单、库存、反馈
- 看不到：师傅的详细工作台、管理功能

### 6.3 管理员权限
- 看到：所有信息、管理功能
- 可以：修改流程、人事安排、处理反馈
