## 核心表结构

### 1. 库存系统

#### suppliers（供应商/厂家）
| 字段 | 类型 | 说明 |
|------|------|------|
| id | INT | 主键 |
| name | VARCHAR(100) | 厂家名称（岳东、易升等） |
| contact | VARCHAR(100) | 联系人 |
| phone | VARCHAR(20) | 电话 |

#### materials（材料主数据）
| 字段 | 类型 | 说明 |
|------|------|------|
| id | INT | 主键 |
| name | VARCHAR(200) | 材料名称（白色38°B料EVA等） |
| category | VARCHAR(50) | 分类 |
| unit | VARCHAR(20) | 单位（张/卷/米） |

#### inventory（库存）
| 字段 | 类型 | 说明 |
|------|------|------|
| id | INT | 主键 |
| supplier_id | INT | 供应商ID → suppliers.id |
| material_id | INT | 材料ID → materials.id |
| specification | VARCHAR(200) | 规格（如 1m*3m*60mm） |
| stock_qty | DECIMAL | 当前库存数量 |

**逻辑**: 同一材料不同供应商、不同规格会有不同库存记录

#### inventory_transactions（库存流水）
| 字段 | 类型 | 说明 |
|------|------|------|
| id | INT | 主键 |
| inventory_id | INT | 关联库存 → inventory.id |
| type | ENUM | inbound/outbound/adjust |
| quantity | DECIMAL | 数量 |
| related_order_id | INT | 关联订单（出库时） |

---

### 2. 排单系统

#### customers（客户）
| 字段 | 类型 | 说明 |
|------|------|------|
| id | INT | 主键 |
| name | VARCHAR(100) | 客户名称（兴达、立优等） |

#### orders（生产订单）
| 字段 | 类型 | 说明 |
|------|------|------|
| id | INT | 主键 |
| order_no | VARCHAR(50) | 订单编号 |
| customer_id | INT | 客户 → customers.id |
| process_type | VARCHAR(100) | 加工工艺（见下方分类） |
| priority | ENUM | 优先级（低/普通/注意/特急） |

**加工工艺分类**（按实际工序组合）：
- `片材` - 只需开片
- `切片` - 只需切片
- `冲型` - 只需冲型
- `片材切片` - 开片→切片
- `片材冲型` - 开片→冲型
- `片材背胶` - 开片→背胶
- `切片冲型` - 切片→冲型
- `片材切片冲型` - 开片→切片→冲型
- `片材背胶切片` - 开片→背胶→切片
- `片材背胶冲型` - 开片→背胶→冲型
- `片材贴布切片冲型` - 开片→贴布→切片→冲型
- `片材背胶切片冲型` - 开片→背胶→切片→冲型（完整工序）
- `库存切片` - 用库存料切片
- `库存冲型` - 用库存料冲型
- `库存切片冲型` - 用库存料切片→冲型
| sheet_material_id | INT | 片材材料 → materials.id |
| sheet_spec | VARCHAR(100) | 片材规格 |
| sheet_qty | DECIMAL | 需求量 |
| sheet_completed | DECIMAL | 已完成量 |
| status | ENUM | 待排产/生产中/已完成/已取消 |

#### order_materials（订单领料）
| 字段 | 类型 | 说明 |
|------|------|------|
| id | INT | 主键 |
| order_id | INT | 订单 → orders.id |
| inventory_id | INT | 库存 → inventory.id |
| required_qty | DECIMAL | 需求数量 |
| issued_qty | DECIMAL | 已发料数量 |

**逻辑**: 订单从库存领料，扣减库存

## 数据流转

### 典型业务流程

```
1. 库存入库
   suppliers + materials → inventory (stock_qty +)

2. 创建订单
   customers → orders (新订单)

3. 订单领料
   inventory (stock_qty -) → order_materials (记录领料)

4. 生产进度
   orders (sheet_completed/slice_completed/punch_completed +)

5. 订单完成
   orders (status = '已完成')
```

## 使用方式

```bash
# 初始化数据库（创建表结构）
npm run init-db

# 导入Excel数据（建立关联）
npm run import-data

# 或一步到位
npm run setup
```
